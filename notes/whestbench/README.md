# WhestBench Phase 2 estimator and diagnostics

Working code for the ARC White-Box Estimation Challenge (Phase 2: width 1024, depth 16, bias-free ReLU,
budget `2^41` FLOPs per network, score `final_layer_mse × max(0.1, C/B)`).

The theory these implement is in [`../groupoid-carrier-and-cartan-truncation.md`](../groupoid-carrier-and-cartan-truncation.md)
and [`../finite-resolution-question-algebra.md`](../finite-resolution-question-algebra.md).

## `estimator.py`

The submitted estimator. Deterministic Gaussian-closure propagation of the layer means and covariances,
corrected at each layer by the leading non-Gaussian structure of the pre-activations:

- **Exact source channel.** The third-cumulant tensor generated by the previous layer's ReLU kinks, in
  factorised diagram form (tree, two-point, diagonal), contracted with the current weights. The source
  coefficients are functions on the unit space (diagonal); the transport is convolution.
- **Monte-Carlo channel.** A small sample (~2400 rows, seeded from `mlp.seed`) resolves the *inherited*
  non-Gaussianity that the one-layer source misses: the third cumulants are fitted against the standardised
  means with a per-layer linear model plus a signal-to-noise shrinkage, the excess kurtosis is a per-layer
  constant, and the two-point cumulants `κ(z_a, z_a, z_b)` are taken rank one along the propagated mean
  direction.
- **Readout.** Edgeworth-corrected rectified mean through third and fourth cumulants, with the matching
  correction to the closure variance.
- **Covariance closure.** Hermite series in the pre-activation correlations with exact ReLU Hermite
  coefficients `d_1 = Φ(t)`, `d_k = φ(t) He_{k-2}(−t)`; exact diagonal; two-point cumulant correction added
  to the off-diagonal.

All arithmetic is float32 through `flopscope`. The normal CDF is an Abramowitz–Stegun 7.1.26 evaluation at
40 FLOPs/element rather than `flops.stats.norm.cdf`, which costs 96 and silently promotes to float64.

### Measured

Official harness, 16-network public shard, `whest run --dataset … --split mini --runner local`:

| metric | value |
|---|---|
| adjusted final-layer score | 9.61e-8 |
| raw final-layer MSE | 9.61e-7 |
| all-layers MSE | 4.70e-7 |
| compute utilisation | 9.79% |
| failed MLPs | 0 of 16 |

For reference the Phase 2 leader is 2.8e-9 adjusted (1.93e-8 raw at 14.7% compute), and bundled covariance
propagation is 4.05e-6.

## Diagnostics

Each script is standalone and reports against the shipped `1e9`-sample ground truth.

| script | what it measures |
|---|---|
| `pass2.py` | per-layer means, covariances and pre-activation raw moments of one network at high sample count (the oracle inputs everything else is scored against) |
| `analyze.py` | per-layer closure error: Gaussian vs Edgeworth readout, modelled vs sampled third cumulants, and the accuracy of the closure variance |
| `offdiag.py` | whether two-point cumulant corrections fix the off-diagonal covariance closure (they cut the induced next-layer variance error ~10×) |
| `oracle_np.py` | error decomposition — oracle covariance vs oracle mean, isolating which closure is binding |
| `twin2.py`, `twin3.py`, `twin4.py` | numpy twins of successive estimator designs, used to sweep configurations without flopscope overhead |
| `rank_test.py` | the spectral-truncation test of the far transport reported in the groupoid note (the negative result) |
| `profile_flops.py` | flopscope budget fraction attributable to each channel |

`twin4.py` carries the switches the note's tables vary: `K` (diagonal source depth), `K21_K` (two-point
source depth), `trank`/`K0` (spectral truncation of far transports), and the Monte-Carlo channel options.
