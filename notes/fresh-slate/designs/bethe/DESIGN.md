# Bethe design stream — node and pair beliefs on the quenched layered graph

Status: v0 (design + first measurements). Principle: **tree-based local-to-global on pseudorandom
geometry** (Bethe / cavity / TAP / loop series), brief idea B of the 1 Oct input.

## 1. The principle, stated precisely

Bethe (region) approximation: the joint law of a system on a graph is represented by **node beliefs**
(single-site marginals) and **edge beliefs** (pair marginals); everything of higher order is
**generated** from them by the tree factorisation p ∝ Π_edges p_ab / Π_nodes p_a^{d_a−1} (for weak
couplings: Kirkwood superposition; in cumulant form: connected k-point functions are *tree diagrams*
whose vertices are local cumulants and whose edges are pair cross-cumulants). On a tree this is
exact. On pseudorandom geometry (large girth, expanders, dense graphs with weak random couplings) the
loop corrections are small in a counted way (Chertkov–Chernyak loop series; TAP/Onsager for dense
weak couplings), and the factorisation becomes asymptotically exact.

Realisation used here (the "dictionary"), for one quenched network:

- Node belief of neuron a in layer l: the law of the pre-activation z_a, carried by (m_a, v_a, κ3_a, κ4_a).
- Edge belief of a pair (a, b) in the same layer: the cross cumulants c_ab = κ(z_a, z_b),
  K_ab = κ(z_a, z_a, z_b), K_ba.
- Higher joint structure (distinct triples) is not a state variable: it is **generated** by the
  tree rule — a hub (a local second-derivative vertex at the centre) with two covariance edges — plus
  what is carried forward linearly from the previous layer (§4.3, "old content").
- The ReLU acts on the beliefs through the **cross-cumulant (Bethe) expansion around the product of
  the node beliefs**:

  E[Π_a f_a(z_a)] = E_{Π_a p_a}[ exp(D) Π_a f_a ],  D = Σ_{cross multi-indices α} κ_α ∂^α / α!,

  an exact identity of characteristic functions (log φ_z = Σ_a log φ_a + cross cumulants). The
  product measure Π p_a is the tree (Bethe / 2-lift-limit) reference; every term of exp(D) − 1 is a
  loop correction attached to the edges it uses.
- The linear layer z' = aW is exact multilinear algebra on the quenched W: the couplings enter
  exactly. Only *what is not carried* (higher cross cumulants) is replaced by the tree rule.

Where the principle is essential: (i) the reference measure for every nonlinear map is the product of
node beliefs (the Bethe/lift limit), (ii) the truncation of exp(D) is ordered by the power counting
of dense random layers (each edge carries n^{-1/2}), (iii) distinct-triple structure is generated by
tree diagrams (hubs), never stored (in the production form).

## 2. Power counting on the dense random layered graph (derivation)

He weights: W_ij ~ N(0, 2/n). Same-layer pairwise correlations are O(n^{-1/2}); the layered graph is
dense with girth 4. Ensemble averages ("self-averaging" quantities) are tree-exact: e.g.
E_W[w^T C w] = (2/n) tr C, the Bethe (lift-limit) value. But the score needs **quenched per-neuron**
values to ~1e-4 rms, and there the counting is different:

| quantity of z_j = Σ_a W_aj a_a | tree (lift-limit) term | 4-cycle (pair) terms | 6-cycle (distinct triple) terms |
|---|---|---|---|
| mean | Σ W μ, O(1), exact | — | — |
| variance quenched part | Σ W² Var a | Σ_{a≠b} W W C_ab, O(n^{-1/2}) | — |
| κ3 (zero in the ensemble) | Σ W³ κ3, O(n^{-1}) | Σ W² W K_ab, O(n^{-1}) | Σ W W W T_abc, O(n^{-1}) |

So the lift-limit (pure node-belief) Bethe estimate is wrong at the *leading* quenched order: the
short loops of a dense graph contribute at the same order as the tree term (their number
compensates their weight). **Negative result of the principle in its naive form: node beliefs alone
cannot work; edge beliefs are necessary, and distinct-triple (6-cycle) structure enters κ3 at the same
order.** This is consistent with the measured fact (brief §3) that per-neuron κ3 carries most of the
missing information.

The pair expansion orders (c ~ n^{-1/2}; K_z ~ n^{-1}; T_z ~ n^{-1}):

- C^a_ab = c L0_a L0_b + ½K_ab L−1_a L0_b + ½K_ba L0_a L−1_b + ½c² L−1 L−1 + [½cK, c³/6 terms],
- K^a_ab = Δ21 − 2μ_a Δ11 (same expansion with f_a = relu²),
- T^a_abc (distinct) = T^z_abc L0_a L0_b L0_c + Σ_{centres b} c_ab c_bc L0_a L−1_b L0_c + O(n^{-3/2}),

where the node "ladder" L_q = G_q + κ3/6 G_{q−3} + κ4/24 G_{q−4}, G_q = E_G[relu^q]/q! for q ≥ 0 and
G_{−k} = ∂_m^k Φ(m/σ): E_node[(relu^p)^{(r)}] = p! L_{p−r} (shift derivatives = Gaussian integration
by parts, Edgeworth to first order). L0 is the corrected gate probability, L−1 the corrected density at 0.

Dropped at this order (the error mechanism, §5): fourth-order cross cumulants Q_ab = κ(z_a,z_a,z_b,z_b),
R_ab = κ(z_a,z_a,z_a,z_b) in the pair map and in κ4(z_j) (only the tree part Σ W⁴ κ4 is carried);
O(n^{-3/2}) triple terms; old distinct-triple content beyond the carried age.

## 3. The estimator

State per layer: m, κ3, κ4 (n-vectors); C, K (n × n).
Per layer: (1) node ladder (n elementwise transcendental ops), (2) pair map (n² elementwise, ~40
flops/pair), (3) linear map:

- m' = μW; C' = Wᵀ C^a W;
- K'_jk = S^a[w_j, w_j, w_k], with S^a assembled from node κ3, pair K^a and generated triples, in five
  n³ products: P1 = K^a_off W; U = c (diag(L0) W); X = κ3∘W∘W + 2 W∘P1 + L−1∘U∘U;
  K' = Xᵀ W + (W∘W)ᵀ P1 + 2 (L−1∘W∘U)ᵀ U;
- κ4' = (W∘4)ᵀ κ4^a (tree).
- Old triple content of age 1 (optional): the same contractions with the gated two-step propagator
  P = W_l diag(L0) W_{l+1} against layer l−1's generated triples: +6 n³ per layer.

Readout: μ = L1 (Edgeworth-corrected relu mean) at every layer.

Reference mode (prototype only, n ≤ 256): S stored as a full n³ tensor and propagated exactly
(S' = S^a ×₁W×₂W×₃W), so old content is kept at all ages. It isolates the closure error of the pair
map from the error of the triple generation.

## 5. Error mechanism and predicted scaling

The final-layer mean error is the accumulation over depth of (a) the dropped fourth cross cumulants
(Q, R), relative O(n^{-1}) in variance-like quantities → mean errors O(n^{-1}) each, partially
coherent over depth; (b) dropped old triple content in κ3 (O(n^{-1}) per neuron, ≈ 40 % of the (2,1)
slice by the brief's measurement) → mean errors O(n^{-1}) × κ3-sensitivity; (c) Edgeworth truncation
(κ3² ~ n^{-2}). Prediction: raw MSE ∝ n^{-2} (per-neuron errors O(n^{-1})), with a prefactor set by
(a)+(b). At n = 1024 an n^{-2} law with an O(1) prefactor is ~1e-6; the bar needs ~1e-8, so the
prefactor must be ≲ 0.01, i.e. the carried terms must capture ~99 % of the O(n^{-1}) corrections,
or the scaling must be steeper (n^{-3} from terms that cancel at leading order).

## 6. Cheapest falsification test

At width 64–256, depth 16: compare reference mode (all old content, full S) with the
production mode (no old triples). If the reference mode's raw MSE does not fall at least ~n^{-2}
and lie ≥ 10× below Gaussian closure, the pair-belief dictionary is falsified at this order
(the next candidate is carrying Q, R — fourth cross cumulants — as edge beliefs).

## 7. Log

- Exactness check 1 (pair map, Gaussian part): for a bivariate Gaussian with |c| = 0.2 → 0.025 the
  expansion error of E[a_a a_b] and E[a_a² a_b] falls 16× per halving of c (c⁴ law, 7e-6 → 1.8e-9),
  i.e. the c, c², c³ terms are exact.
- Exactness check 2 (layer map with the triple hubs, n = 12, MC 4e6): C^a, K^a, T^a errors at MC noise
  for |c| ≤ 0.2; T^a hub closure 10 % off at |c| ≈ 0.5 (expected next order).
- Exactness check 3 (exact edge table, v1): the bivariate-Gaussian table G_ij (i, j ∈ [−4, 3]; Φ2 by
  40-node Gauss–Legendre in θ = asin ρ; Stein recursion G_pq = (m_a G_{p−1,q} + v_a G_{p−2,q} + c G_{p−1,q−1})/p;
  negative indices from the conditional law at z = 0) matches adaptive quadrature to 1e-16 for ρ = 0.3, 0.9,
  0.99, and its mean-derivatives match finite differences to 1e-11.

## 9. Diagnosis (w64, MLPs 0–1, MC 4e6)

Oracle injection of true z-state pieces at every layer (final MSE; none = 1.65e-4 / 8.8e-5):
true (v, κ3, κ4) at every node → 9.4e-6 / 9.3e-6 (17× / 9×), identical to injecting (C, K, κ4) in full:
**the pair (off-diagonal) parts of the state are not what is binding; the node beliefs are.**
Injecting true κ4 alone makes it 3–6× worse (my κ3, v are tuned to my κ4 ≈ 0).

Node-belief errors along depth (own chain vs MC truth, MLP 0): variance rel. err. grows to 5–10 %;
κ3 rel. err. 0.4–0.6; **κ4 rel. err. ≈ 1: the true node κ4 is large and coherently positive
(mean 0.1–0.3, rms 0.2–0.8), whereas the tree κ4 decays to ≈ 0.** Adding the two-site (Q, R) and the
generated (2,1,1)/(1,1,1,1) tree terms to κ4 (v2) does not fix it (still ~0 mean).

Interpretation (the cavity picture done right): the cavity field of a neuron in a dense random layer is
Gaussian **conditionally on the global order parameter** q_l(x) = |a_l(x)|²/n (the layer self-overlap,
starting with the input radius |x|²/n), whose O(n^{-1/2}) fluctuation is shared by *all* neurons. It
modulates every variance at once, so it is invisible to any pair-local edge belief that starts with
Q^z = 0, yet it contributes κ4 ≈ 3 Var(q)/q̄² v² = O(1/n) to every node, growing with depth (the
finite-width "4-point vertex" of deep-network theory). This is the replica/cavity order-parameter
fluctuation, i.e. a loop correction that the dense graph sums coherently. Next: carry it.

## 11. The global order parameter (v3/v4)

True Q^z = κ(z_a, z_a, z_b, z_b) at w64 (MLP 0, MC 1e6) has a **dominant rank-one spike** (top eigenvalue
5–9, next ≈ 1); fitted as ε v_a v_b, ε grows with depth (0.06 at layer 1 → 0.74 at layer 15, vs 2/n =
0.03 for the input radius alone). Normalising the input to the sphere removes about a third of it at
layer 1 and a quarter at depth: the input radius seeds it, the layers amplify it.
Carrying Q^z as an edge belief (Q' = (W∘W)ᵀ(Q^a + diag κ4^a)(W∘W) + hub generation; κ4 from two-site +
tree terms) reproduces the mean node κ4 along depth (w64: 0.32/0.35/0.25/0.24/0.28 vs true
0.32/0.32/0.22/0.19/0.23). Feeding Q into the pair map by Edgeworth is singular as ρ → 1 (the δ⊗δ term);
treating it as a per-pair variance scale mixture (3-point Gauss–Hermite in η) is smooth.
