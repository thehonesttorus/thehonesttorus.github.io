## 1. The estimator, step by step

**"wmc" = Whitened Monte Carlo** ("Whitened (moment-matched) Monte-Carlo estimator"). Everything is a float32 sample mean of forward passes; nothing analytic enters the scored layer except (a) the exact layer-1 moments in the anchor builds and (b) the exact "always-on" shortcut, which is an identity, not an approximation.

### 1.0 Core algorithm (common to wmc2 → merge), from WRITEUP §6.0 + code
```
k  = sample_count(budget)        # WORST-CASE sizing: assume NOTHING prunes
xh = standard_normal(k/2, n) float32; ensemble X = [xh ; -xh]   (antithetic)
G  = (2/k) xh^T xh               # Gram of the FULL ensemble via the half (x^T x == 2 xh^T xh)
W0f = G^(-1/2) W0                # whitener FUSED into W0 (eigh, evals floored 1e-6): n^3 not k n^2
Z  = W0f^T xh^T  (ONE matmul for both halves, sweep/merge only)
Y  = [ReLU(Z), ReLU(Z) - Z]      # ReLU(-z) == ReLU(z) - z exactly in IEEE
layers 1..6 (head): dense, carried TRANSPOSED (width, samples), exact dead-ROW pruning
lead_pass(Y[:, :1024]): run 1024 samples at full width through layers 7..31 -> static alive masks
layers 7..30 (tail): Y = ReLU(W_l[ix_(mask_{l-1}, mask_l)]^T Y) on the masked index space
scored layer: classify columns dead / always-on / kink from lead-block Z_31; evaluate only kink columns
return row_sums / k   (shape (depth, width))
```
Devices, exactly as the repo labels them:
- **Whitening** = moment matching: force empirical mean = 0 and empirical second moment = I exactly ("An affine re-standardisation of an i.i.d. Gaussian ensemble is still a valid N(0,I) ensemble, but its first- and second-moment sampling error is now identically zero"). In Hermite-chaos terms: removes chaos degrees 1 and 2 "in all 256 dimensions, for free".
- **Antithetic pairs** {±x}: every odd empirical moment zero; "removes every odd degree". Residual: `MSE = 2·Σ_{even d≥4} V_d / k`. Antithetic ALONE is harmful (measured 0.82× / 9.11e-06 vs 6.38e-06 plain), only pays on top of whitening.
- **Fusion**: whitener into W0 ("turns a k·n² pass into an n³ one and buys back ~3 % more samples").
- **float32**: "exactly half the metered price of float64"; float32 forward error 9.2e-13 MSE vs float64.
- **Exact dead-column pruning** (wmc2): `Y_l @ W_{l+1} == Y_l[:, A_l] @ W_{l+1}[A_l, :]` where A_l = neurons firing on ≥ 1 sample of the block; "an algebraic identity on the block"; pruned vs unpruned MSE ratio 1.000014 (float32 summation order); bit-identical at fixed permutation (cost-floor probe, 12/12 MLPs, max deviation 0.000e+00).
- **Lead-block masking** (wmc3, "a-priori", two-sided): first `_LEAD = 1024` samples at full output width; alive set FROZEN as static mask; the ONLY approximate step: bias² = 1.5e-09 = 0.47 % of MSE, does not shrink with k. Scored layer never masked on the output side.
- **Final-layer classification** (wmc3): with `_FINAL_MARGIN = 1.0` sd band on lead-block pre-activations: `on := min_t Z_j > +margin·sd_j → mean_s ReLU(z_j) = w_j · mean_s(y_{L−1})` EXACTLY (sample mean commutes with a linear map); `dead := max_t Z_j < −margin·sd_j → 0`; kink: full k-sample column. ~45 % of scored columns classify; misclassification 0.25 false-on / 0.50 false-dead per MLP; dMSE/MSE = −7.7e-07.
- **Gram halving** (wmc3): xᵀx == 2 xhᵀxh (1.073676e9 → 5.368054e8 FLOPs).
- **Strassen–Winograd** (wmc4): `_smm` recursion `_LEVELS = 2`, `_MIN_DIM = 48`; exact meter cost `_mm_cost(m,k,n,lv) = 7·_mm_cost(h,i,j,lv−1) + 5hi + 5ij + 8hj + 2mn` (matmul bills 2mkn − mn; adds/concat 1/elem). Masks rounded up to multiples of 2^levels by re-adding dead neurons (conservative); k rounded to a multiple of 2·2^levels.
- **Sizing**: `_TARGET_UTILISATION = 0.92` of budget under a nothing-prunes cost model; executes at ~0.66–0.68. Per-sample worst-case model (wmc3): draw 16n/2 + 3n; Gram n²; layer0 2n² + n; layers 1..d−1: (2n² + 8n) each; fixed: 9n³ (eigh) + 2·2n³ + 16n² + 48·depth·n² slack. Fallback ladder has EXACTLY ONE expensive rung (MC → `_mean_propagation` ~2e8 FLOPs, scores ~9.5e-05 → zeros); early divergence abort after the head.
- **No cubature, no QMC, no control variates, no Mehler series, no active subspace, no MLMC in any shipped estimator** — all were probed and rejected (§2).
