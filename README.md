# thehonesttorus.github.io

Notes on noncommutative geometry as a framework for machine learning.

- [Inputs as states on a finite-resolution question algebra](notes/finite-resolution-question-algebra.md) — the 0/1 activation code, why finite-resolution states do not transport through ReLU layers, and what this says about the ARC White-Box Estimation Challenge (with numerical checks in `notes/checks/`).
- [The network as a groupoid convolution algebra, and which truncations are admissible](notes/groupoid-carrier-and-cartan-truncation.md) — a neuron is a unit rather than an edge, the activation is a state-dependent Cartan projection, and the finite-resolution truncation this rules out (with the estimator and diagnostics in `notes/whestbench/`).
